# CodePatcher

تطبيق ويب (PWA) واحد بلا أدوات بناء. يعمل بفتح `index.html` مباشرة أو من خادم.

## البنية
- `index.html` — الهيكل (HTML فقط) + وسوم `<script>` بالترتيب.
- `css/` — `base` ← `editor` ← `ui` ← `theme-light` (الترتيب مهم).
- `js/NN-اسم.js` — سكربتات عادية (ليست ES modules، لأن الملف المباشر `file://` لا يدعمها). تتشارك النطاق العام، والرقم هو ترتيب التحميل.
- `sw.js` — service worker، يخزّن كل الملفات؛ **ارفع رقم `codepatcher-vN` عند إضافة/حذف ملف**.
- `js/16b-text-bundle.js` — تصدير المشروع كنص واحد (مع خريطة وتقسيم لأجزاء) واستيراده (حزمة أو خريطة بلا محتوى، مع اختيار اسم المشروع ومكان التوليد). الصيغة: `=== FILE: path (N lines) ===`.
- `tools/check.js` — `node tools/check.js` يفحص الصياغة والتسجيل والأسماء المكررة.

## قواعد عند التعديل
1. ملف جديد: أضفه في `index.html` وفي قائمة `sw.js`، ثم شغّل `node tools/check.js`.
2. لا تستدعِ دالة معرّفة في ملف **لاحق** أثناء التحميل (خارج أي دالة). داخل الدوال لا مشكلة. الدوال المطلوبة مبكراً مكانها `03-utils.js` (مثل `ic`).
3. `29-patch-history.js` يلفّ `runPatchEngine` و`applyPatch` فيجب أن يبقى آخر ملف.
4. بعد أي تعديل: افتح التطبيق ← الإعدادات ← الاختبار الذاتي (يجب 119/119).
